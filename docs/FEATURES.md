# 기능 명세와 현재 상태

상태 표시는 현재 `main` 구현을 기준으로 합니다.

## 사용자와 인증

| 기능 | 상태 | 기준 |
| --- | --- | --- |
| 이메일 인증코드 요청·검증 | 제공 | 가입·비밀번호 복구 목적 분리, 만료·시도·일별 요청 제한 |
| 회원가입·로그인·로그아웃 | 제공 | HttpOnly 쿠키 세션과 Bearer 호환 |
| 세션 복구 | 제공 | 새로고침 후 `/api/auth/me`로 복원 |
| 비밀번호 변경·임시 비밀번호 발급 | 제공 | 이전 세션 무효화 |
| 계정 삭제 | 제공 | 현재 비밀번호 재확인 |
| 네이티브 소셜 로그인 | 미제공 | 앱스토어 출시 단계에서 검토 |

## 여행

| 기능 | 상태 | 기준 |
| --- | --- | --- |
| 여행 목록·생성·수정·삭제 | 제공 | 제목, 기간, 국가, 동행자, 내부 메모 |
| 전 세계 목적지 구조 | 제공 | 국가 코드 기반, 상하이는 시작 데이터 제공 |
| 소유자 여행 보기 | 제공 | 오늘·일정·지도·항공·긴급·마이페이지 |
| 탭 직접 링크·새로고침 복원 | 제공 | URL 해시로 보기 상태 유지 |
| 실시간 공동 편집 | 미제공 | 현재 owner 단독 변경 |

## 장소와 지도

| 기능 | 상태 | 기준 |
| --- | --- | --- |
| 장소 직접 등록·수정·삭제 | 제공 | 좌표는 선택 입력 데이터이며 사용자 수기 입력 UI는 기본 흐름이 아님 |
| Google Places 검색 | 제공 | 카페·식당·관광지·숙소 등 텍스트 검색 |
| 검색 결과 현지어·한국어 표시 | 제공 | 제공 가능한 이름·주소를 함께 유지 |
| 검색 장소 좌표와 Place ID 저장 | 제공 | 지도 핀과 일정 연결에 사용 |
| 앱 내부 지도 | 제공 | 저장 장소, 일정 연결 장소와 현재 위치 표시 |
| Google·고덕지도 길찾기 선택 | 제공 | 중국 목적지는 두 서비스 선택, 그 외 Google 기본 |
| 지도 실패 대체 화면 | 제공 | 장소 목록·주소·외부 길찾기 유지 |
| 턴바이턴 내비게이션 | 미제공 | 외부 지도 앱의 역할 |

## 일정과 준비물

| 기능 | 상태 | 기준 |
| --- | --- | --- |
| 날짜별 일정 CRUD | 제공 | 여행 기간 안의 날짜만 허용 |
| 장소 검색 후 일정 연결 | 제공 | 저장 장소를 일정에서 선택 |
| 날짜별 일정 정렬·완료 | 제공 | 모바일 조작과 상태 저장 |
| 날짜 탐색 | 제공 | 1~4일 한 줄, 5일 이상 가로 스크롤 |
| 여행 전체 체크리스트 | 제공 | 모든 날짜에서 한 번만 확인 |
| 날짜별 체크리스트 | 제공 | 특정 여행 날짜에만 표시 |
| 체크리스트 CRUD·완료 | 제공 | API 영구 저장 |

## 공유와 오프라인

| 기능 | 상태 | 기준 |
| --- | --- | --- |
| 공유 링크 생성 | 제공 | 예측하기 어려운 토큰 기반 |

| 네트워크 상태 안내 | 제공 | 일시적 연결 전환을 고려한 복구 안내 |
| 최근 데이터 오프라인 복원 | 제공 | 읽기 중심, 네트워크 연결 또는 API 서버 복구 시 공유 데이터를 자동 갱신하고 변경은 온라인 필요 |
| 입력 중 업데이트 보호 | 제공 | 폼을 잃지 않는 서비스 워커 적용 |
