# 비밀번호 찾기 모달 복구 설계

## 목표

모바일 비밀번호 찾기 모달의 입력창이 사용 가능한 폭을 채우지 못하는 레이아웃 회귀를 수정하고, 사용자가 모달 안에서 인증코드를 요청한 뒤 임시 비밀번호를 발급받을 수 있는 완결된 흐름을 제공한다.

## 확인된 문제

- 376px 모바일 뷰포트에서 폼 폭은 288px이지만 입력창은 브라우저 기본 폭인 185px만 사용한다.
- `ForgotPasswordModal`의 폼에 `.auth-form` 클래스가 없어 공통 입력 규칙인 `width: 100%`, 최소 높이 48px, 포커스 스타일이 적용되지 않는다.
- 모달은 인증코드를 입력하라고 안내하지만 비밀번호 찾기 목적의 인증코드를 요청하는 동작을 제공하지 않는다.
- 오버레이, 카드, 버튼에 인라인 스타일이 집중되어 반응형 규칙과 접근성 상태를 검증하기 어렵다.
- 닫기 버튼과 모달 컨테이너에 충분한 접근성 이름과 dialog 의미가 없다.

## 선택한 접근법

현재 모달과 기존 인증 API를 재사용하는 표적 복구를 수행한다. 별도 페이지나 새 API, DB 변경은 추가하지 않는다.

### 컴포넌트 구조

`ForgotPasswordModal`은 다음 요소로 구성한다.

1. `role="dialog"`, `aria-modal="true"`를 가진 오버레이와 모달 카드
2. 제목, 짧은 설명, 접근 가능한 닫기 버튼
3. 이메일 입력과 `인증코드 받기` 버튼
4. 6자리 인증코드 입력
5. 취소와 `임시 비밀번호 생성` 행동
6. 발급 성공 시 임시 비밀번호와 `복사하고 닫기` 행동

모달 전용 클래스는 `manage.css`에 두고 기존 Pocket Atlas 토큰과 공통 `.auth-form`, `.primary-button`, `.secondary-button`을 재사용한다. 인라인 레이아웃 스타일은 제거한다.

## 사용자 흐름

### 인증코드 요청

1. 사용자가 가입 이메일을 입력한다.
2. `인증코드 받기`를 누르면 `sendVerificationCode(email, "forgot")`를 호출한다.
3. 성공하면 이메일로 6자리 코드가 전송되었다는 상태를 표시한다.
4. 개발 환경에서 API가 코드 값을 반환하면 가상 수신 코드로 화면에 표시할 수 있다.
5. 실패하면 API 오류 문구를 모달 안에 표시하고 기존 입력을 유지한다.

### 임시 비밀번호 발급

1. 이메일과 6자리 코드를 입력한다.
2. `forgotPassword(email, code)`를 호출한다.
3. 성공하면 발급된 8자리 임시 비밀번호를 읽기 쉬운 결과 패널에 표시한다.
4. 사용자가 복사하고 모달을 닫아 로그인 화면으로 돌아간다.
5. 실패하면 코드 만료·불일치 등 API 오류를 표시하고 다시 입력할 수 있게 한다.

## 반응형·시각 규칙

- 입력창과 입력 래퍼는 항상 동일한 가용 폭을 사용한다.
- 입력과 주요 버튼은 최소 높이 48px, 기타 터치 대상은 최소 44px을 유지한다.
- 360px 이하에서는 취소와 생성 버튼을 한 열로 배치한다.
- 모달 카드는 작은 화면에서 좌우 16px 이상 여백을 유지하고, 내용이 길거나 키보드가 열리면 내부 스크롤이 가능해야 한다.
- 일반 카드는 그림자 없이 유지하되 실제 오버레이인 모달에는 디자인 시스템의 Overlay Lift만 사용한다.
- 청록색은 주요 행동과 성공 상태에만 사용하고 코랄·골드·그라디언트는 추가하지 않는다.

## 접근성·오류 처리

- 모달 제목과 설명을 `aria-labelledby`, `aria-describedby`로 연결한다.
- 닫기 버튼의 접근성 이름은 `비밀번호 찾기 닫기`로 제공한다.
- 오류는 `role="alert"`, 전송 성공 상태는 `role="status"`로 알린다.
- 요청 중에는 중복 전송을 막고 버튼 문구를 `전송 중`, `발급 중`으로 변경한다.
- 이메일 형식이 명백히 잘못된 경우 외부 요청 전에 사용자가 이해할 수 있는 오류를 표시한다.
- 인증코드 입력은 숫자 키패드를 요청하고 최대 6자리로 제한한다.

## 테스트

### 컴포넌트 테스트

- 모달이 dialog 의미와 접근 가능한 제목·닫기 버튼을 제공한다.
- 이메일과 인증코드 입력이 공통 전체 폭 폼 구조 안에 렌더링된다.
- `인증코드 받기`가 기존 API를 `forgot` 목적으로 호출한다.
- 인증코드 전송 성공·실패 상태를 표시한다.
- 이메일과 코드 제출 시 임시 비밀번호를 표시하고 복사 흐름을 제공한다.

### 브라우저 회귀 검사

376px 뷰포트에서 다음을 계산값으로 확인한다.

- 입력창 폭이 입력 래퍼 폭의 98% 이상이다.
- 모달 카드가 뷰포트를 넘지 않는다.
- 모든 입력과 행동이 가로 스크롤 없이 보인다.

## 비목표

- 비밀번호 재설정 API와 사용자 테이블 변경
- 인증코드 정책·만료 시간·일일 발송 제한 변경
- 로그인·회원가입 화면 전체 재설계
- 임시 비밀번호 대신 사용자가 새 비밀번호를 직접 설정하는 서버 흐름 도입
