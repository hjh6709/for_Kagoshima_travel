# 프로덕트 요구사항 문서

## 1. 한 줄 정의

장소 검색, 날짜별 일정, 준비물과 길찾기를 하나의 여행 맥락으로 연결하는 모바일 우선 여행 플래너.

## 2. 배경

Map Planner는 부모님의 가고시마 여행을 돕기 위한 개인용 여행 도우미에서 시작했습니다. 이후 실제 사용자가 자신의 여행을 만들고 동행자에게 공유할 수 있는 서비스로 확장했으며, 상하이 여행을 첫 운영 사례로 검증하고 있습니다. 특정 도시 전용 앱이 아니라 한국을 포함한 전 세계 여행을 지원하는 것이 최종 방향입니다.

여행 정보가 지도, 메신저, 예약 앱과 메모에 흩어지면 사용자는 현장에서 다음 행동을 빠르게 판단하기 어렵습니다. 특히 작은 모바일 화면, 강한 야외 빛, 불안정한 네트워크와 한 손 사용을 고려해야 합니다.

## 3. 대상 사용자

### 여행을 만드는 사람

- 여행의 날짜·국가·동행자를 정합니다.
- 카페, 식당, 관광지, 숙소를 검색해 저장합니다.
- 장소를 날짜와 시간 순서의 일정에 연결합니다.
- 항공편과 준비 체크리스트를 관리합니다.
- 동행자에게 읽기 전용 공유 링크를 전달합니다.

### 여행에 참여하는 사람

- 로그인 없이 공유 링크로 최신 여행을 확인합니다.
- 오늘 일정, 지도, 항공편과 긴급 정보를 빠르게 찾습니다.
- 내부 메모나 계정 정보는 볼 수 없습니다.

## 4. 해결해야 하는 핵심 질문

1. 지금 또는 선택한 날짜에 어디로 가야 하는가?
2. 저장한 장소가 지도에서 어디에 있고 다음 이동은 무엇인가?
3. 출발 전과 각 여행 날짜에 무엇을 준비해야 하는가?
4. 네트워크나 지도 로딩이 실패해도 필요한 정보를 계속 확인할 수 있는가?
5. 여행을 만드는 사람과 공유 링크를 보는 사람의 데이터 경계가 안전한가?

## 5. 제품 원칙

- 좌표를 사용자가 직접 입력하게 하지 않습니다.
- 일정은 시간 중심, 지도는 공간 중심으로 역할을 구분하면서 서로 같은 날짜와 장소 맥락을 유지합니다.
- 한 화면에서 우선 행동을 분명히 하고 편집을 위해 불필요하게 여러 화면을 왕복하지 않게 합니다.
- 장소명과 핵심 행동은 작은 모바일과 야외에서도 읽을 수 있어야 합니다.
- 색상만으로 상태를 설명하지 않고 텍스트·아이콘·선택 상태를 함께 제공합니다.
- 외부 API 실패와 오프라인 상태를 정상적인 여행 환경으로 취급합니다.
- 공개 공유 응답은 허용 목록 방식으로 구성합니다.

## 6. 출시 범위

### 제공 중

- 이메일 인증, 로그인, 세션 복구, 비밀번호 변경·복구, 계정 삭제
- 여행 CRUD와 국가별 시작 데이터
- 장소 검색·저장·수정·삭제
- 날짜별 일정과 장소 연결, 정렬, 완료 상태
- 전체·날짜별 체크리스트
- 앱 내부 지도와 외부 길찾기 선택
- 항공편, 긴급 정보, 현지 도구
- 읽기 전용 공유 링크
- 설치 가능한 PWA, 업데이트·오프라인 안내

### 출시 전 계속 강화

- 실제 기기 회귀 테스트와 접근성 검증 자동화
- 로그인·여행 생성의 첫 사용 흐름 단순화
- 편집 화면 간 이동과 저장 피드백 일관성
- 장애 관찰성, 백업 복구 훈련과 운영 알림
- 앱스토어 출시를 위한 네이티브 셸·권한·심사 정책 검토

### 현재 비범위

- 앱 내부 턴바이턴 내비게이션
- 실시간 공동 편집
- 현재 위치의 서버 저장
- 사용자가 직접 관리하는 지도 API 키
- 결제·예약 대행

## 7. 출시 판단 기준

- 회원가입부터 첫 여행·장소·일정·체크리스트 생성까지 모바일에서 막힘 없이 완료됩니다.
- 공유 링크가 최신 여행을 표시하며 비공개 필드를 노출하지 않습니다.
- 지도 실패 시에도 장소와 외부 길찾기 기능을 사용할 수 있습니다.
- 주요 터치 대상은 최소 44px이고 일반 텍스트 대비는 WCAG AA 기준을 충족합니다.
- 프런트엔드 전체 테스트·타입 검사·빌드와 API 테스트·정적 분석·보안 검사가 통과합니다.
- main 배포 실패 시 OCI API가 이전 정상 바이너리로 자동 복구됩니다.

세부 기능 상태는 [`FEATURES.md`](./FEATURES.md), 기술 경계는 [`TECH_DESIGN.md`](./TECH_DESIGN.md)를 기준으로 합니다.
